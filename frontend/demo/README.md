# 기존 시연 UI

이 폴더는 폴더 분리 이전의 HTML/CSS/JavaScript 시연 화면입니다. 팀원이 작성한 React 프런트엔드는 상위 `frontend/src/`에 있습니다.

루트에서 `npm run dev`로 백엔드를 실행한 뒤 `http://localhost:3000`에서 기존 화면을 볼 수 있습니다. 이 화면은 백엔드의 `/api/status`, `/api/analyze`에 연결되어 있고 API 키 없이 가상 시연을 할 수도 있습니다.

프런트엔드 통합 방향이 정해질 때까지 기존 코드를 보존합니다.

## PC 카메라 문제 확인

카메라를 켜면 촬영 버튼 아래에 **사용할 카메라** 목록이 표시됩니다. Windows 카메라 앱은 정상인데 웹에 빨간 X나 검은 화면이 보이면 이 목록에서 실제 내장/USB 웹캠을 선택하세요. 가상 카메라가 선택되어 있을 수 있지만 이것만이 원인이라고 확정할 수는 없습니다.

장치가 하나뿐이거나 계속 실패하면 Chrome/Edge의 카메라 설정에서 선택 장치를 확인하고, 다른 브라우저와 사진 업로드로 분리해서 점검합니다. 카메라 오류는 이름에 따라 권한·장치 없음·영상 읽기 실패 등으로 구분해 안내합니다. 카메라 장치 이름과 ID는 서버에 보내지 않습니다.
